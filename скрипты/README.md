# 📜 Скрипты (JSON)

В этой папке — **все скрипты проекта** в виде наглядных JSON-файлов
с русскими названиями. Внутри каждого JSON:
- `имя` — название;
- `описание` — что делает;
- `язык` — язык кода;
- `исходный_путь` — где лежит оригинал (папка `scripts/` или `tests/`);
- `код` — полный исходный код скрипта.

## 📂 Файлы

| Файл | Что внутри |
|---|---|
| `генератор-графики-рыбной-печки.json` | Генерация всех спрайтов мода (чешуя, глаза, пламя 48 кадров, тень, останки). Python + Pillow. |
| `генератор-миниатюры-мода.json` | thumbnail.png 512×512 для мода. |
| `кодек-чертежей-factorio-2.json` | Библиотека: строки чертежей ↔ JSON, конструкторы сущностей/проводов/сигналов/расписаний. |
| `примеры-чертежей.json` | Демо-чертежи (плавка, логика, книга). |
| `чертёж-железные-шестерни-генератор.json` | Генератор чертежа AM3 → железные шестерни. |
| `создать-мод-из-шаблона.json` | new_mod: новый мод из шаблона. |
| `собрать-мод-в-zip.json` | build_mod: проверка + сборка zip мода. |
| `смоук-тест-мода.json` | Проверка прототипов мода в LuaJIT. |
| `тест-кодека-чертежей.json` | Тесты round-trip на реальных строках 2.0. |
| `экспорт-скриптов-в-json.json` | Сам экспортёр: пересобирает эту папку из исходников. |

## 🔄 Обновление

После правки любого скрипта в `scripts/` перегенерируй JSON:

```bash
python3 scripts/export_scripts_to_json.py
```

Оригиналы (исполняемые) находятся в `scripts/` и `tests/`.
