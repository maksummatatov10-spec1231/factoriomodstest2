## Локальные пути (твоя машина)

- Моды: `%APPDATA%\Factorio\mods` (Win) · `~/.factorio/mods` (Linux) · `~/Library/Application Support/factorio/mods` (macOS)
- Данные игры (для чтения исходников): `<установка>/data/{base,core,quality,elevated-rails,space-age,recycler}`
- Документация: `<установка>/doc-html/` (в т.ч. `auxiliary/data-lifecycle.html`)
- Логи: `factorio-current.log`, `factorio-previous.log`
