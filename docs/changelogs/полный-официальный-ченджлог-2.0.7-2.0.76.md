# Полный официальный ченджлог Factorio 2.0.x (2.0.7 – 2.0.76)

> Источник: официальный репозиторий Wube Software **wube/factorio-data** (файл `changelog.txt`, теги версий).
> Репозиторий: https://github.com/wube/factorio-data · Официальные посты версий: https://forums.factorio.com/ (раздел Announcements)
> Версии 2.0.0–2.0.6 были закрытыми сборками для тестеров перед публичным релизом 21.10.2024 и публичных ченджлогов не имеют.
